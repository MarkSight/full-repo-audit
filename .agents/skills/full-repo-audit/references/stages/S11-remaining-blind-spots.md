# S11 剩余盲区

覆盖之前没有触及的领域。**每个维度一轮。** 开始本阶段前读 S01-S10 摘要。

---

## 依赖与供应链

## S11.01 依赖已知漏洞

**定位**：依赖清单与锁文件。

- 运行依赖审计工具（`npm audit` / `pip-audit` / `govulncheck` / `cargo audit` 等）
- 判断漏洞代码是否真的被调用（可达性），不可达的降级
- 直接依赖与传递依赖分开处理

## S11.02 过时与停止维护的依赖

- 落后多个主版本的依赖
- 已废弃、已归档、长期无人维护的依赖
- 同一用途引入了多个库（两个 HTTP 客户端、两个日期库）

大版本升级只列清单与风险，不自动升级。

## S11.03 peer 依赖与运行时版本

- peer dependencies 冲突
- 声明的语言 / 运行时版本要求与 CI、Dockerfile、生产环境是否一致

## S11.04 许可证合规

- copyleft 许可证（GPL / AGPL / SSPL）与本项目分发方式是否冲突
- 无许可证或许可证不明的依赖
- 需要保留版权声明的依赖是否有归属文件

## S11.05 供应链完整性

- 安装期脚本（postinstall 等）做了什么，是否从网络下载二进制
- 通过 git 地址、tarball 地址、本地路径引用的依赖
- 近期新增依赖中名字与知名包近似、下载量极低的可疑包

## 隐私

## S11.06 个人信息盘点与日志泄露

**定位**：用户数据模型、日志调用、错误上报、分析埋点。

- 哪些字段属于个人信息（含 IP、设备 ID、位置、聊天内容、上传文件）
- 个人信息是否进入日志、错误上报、分析事件
- 是否有统一的脱敏处理

## S11.07 用户数据导出与删除

**定位**：账号注销、数据导出、删除相关功能。

- 用户数据导出、删除是否有实现路径
- 删除是否覆盖关联数据、缓存、搜索索引、对象存储
- 软删除的数据是否永久堆积

## S11.08 第三方数据发送

**定位**：调用第三方服务、AI 模型、分析平台的代码。

- 用户内容被发送到哪些第三方
- 是否有开关与告知
- 发送前是否去除了不必要的个人信息

## 进程与配置

## S11.09 优雅关闭与信号处理

**定位**：服务入口、worker 入口、信号处理。

- SIGTERM / SIGINT 处理
- 停止接收新请求，等待进行中的请求完成
- 关闭连接池，flush 缓冲与日志

## S11.10 在途任务、落盘与子进程

**定位**：后台任务、嵌入式数据库、子进程调用、临时文件。

- 进行中的后台任务在关闭时如何处理（完成、释放租约、可恢复）
- SQLite checkpoint、缓冲写入是否落盘
- 子进程回收，临时文件清理

## S11.11 安全响应头与 CSP

**定位**：Web 框架或服务器的响应头配置。无 HTTP 服务时跳过。

- CSP（是否 `unsafe-inline` / `unsafe-eval`）
- HSTS、`X-Content-Type-Options`、`Referrer-Policy`、frame 防护
- 私有响应的缓存控制头

## S11.12 框架配置深度

**定位**：Web 框架配置文件。

- rewrites / redirects 规则
- 图片与静态资源配置
- 打包与编译器选项
- 实验性功能开关及其风险

## S11.13 配置启动校验

**定位**：配置加载代码。

- 必需配置缺失或格式错误时是否在启动时报错
- 配置来源的优先级（默认值 → 文件 → 环境变量 → 参数）是否明确
- 环境判断是否散落在各处

## S11.14 特性开关债务

**定位**：特性开关定义与读取处。无特性开关时跳过。

- 长期存在、早该移除的开关
- 开关组合产生的未测试状态
- 开关读取失败时的默认值是否安全

## 竞态

## S11.15 跨标签页通信与多连接

**定位**：BroadcastChannel、storage 事件、SSE / WebSocket 连接管理。无客户端时跳过。

- 多个标签页各自建立重复的实时连接
- 标签页之间的状态同步与冲突
- 一个标签页登出后，其他标签页的状态

## S11.16 多实例与多标签页的写入冲突

**定位**：本地数据库写入、画布 / 编辑器保存、后台任务调度。

- 本地数据库的并发写入冲突
- 画布 / 编辑器在多个标签页同时编辑时的覆盖
- 同一任务被多个标签页或多个服务实例重复触发

## 滥用与配额

## S11.17 限流与真实 IP

**定位**：限流中间件、代理配置。

- 是否有限流，限流维度（IP / 用户 / 租户 / 接口）
- 部署在代理之后时能否拿到真实 IP（`X-Forwarded-For` 的信任链）
- 多实例下限流计数是否共享

## S11.18 请求大小上限与 ReDoS

**定位**：请求体解析、上传处理、分页参数、正则表达式。

- 请求体、上传文件、解压后大小是否有上限
- 分页 limit 是否有上限
- JSON 嵌套深度、数组长度
- 用户输入参与的正则是否有回溯爆炸风险

## S11.19 昂贵操作的成本上限

**定位**：AI 调用、导出、报表、批量处理、图像处理。

- 是否有单用户 / 单租户的用量上限
- 同一用户并发触发昂贵任务时是否去重
- 计费与额度是否在服务端强制

## 数据安全

## S11.20 备份与恢复

**定位**：备份脚本、运维文档、存储配置。无自管存储时跳过。

- 是否有备份，频率与保留期
- 是否有写下来的恢复步骤，是否演练过
- 备份是否加密，访问控制

## S11.21 硬删除防护与数据丢失路径

**定位**：删除接口、批量删除脚本、上传流程、导入导出。

- 硬删除、批量删除有无确认、软删除过渡或审计记录
- 进程被杀时内存中未落盘的数据
- 上传中断留下的孤儿文件
- 导出再导入是否无损

## 时间与精度

## S11.22 时区与日期边界

**定位**：日期时间处理、定时任务。

- 存储是否统一 UTC，展示是否按用户时区
- 「今天 / 本月」这类边界按哪个时区计算
- 测量耗时是否使用单调时钟
- 客户端时间是否被用于业务判断

## S11.23 金额精度与单位

**定位**：金额计算、数值换算、超时与 TTL 配置。

- 金额是否使用浮点数计算
- 四舍五入规则与方向
- 毫秒与秒混用（超时、TTL 的常见事故）
- 整数溢出与除零

## S11.24 字符编码与截断

**定位**：字符串截断、长度校验、编码转换。

- 按字节截断导致多字节字符乱码
- 长度校验按字节还是按字符
- emoji 与组合字符的处理
- unicode 规范化对比较与唯一性的影响
