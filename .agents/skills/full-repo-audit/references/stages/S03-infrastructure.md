# S03 底层穿透

深入代码基础设施层。**每个维度一轮。** 开始本阶段前读 S01、S02 摘要。

---

## 类型安全

## S03.01 类型逃逸口

**定位**：强制类型转换、`as`、`any`、类型忽略注释、`unsafe`。动态语言改查缺少类型标注的公共函数。

- 逐个判断是否必要，不必要的改为正确类型
- 必要的是否有注释说明为什么安全
- `any` 是否通过返回值扩散到调用方

## S03.02 边界数据未校验

**定位**：请求体解析、第三方 API 响应、JSON 解析、文件读取、数据库读取的结果。

- 外部数据未经 schema 校验，直接断言成内部类型
- 校验之后，后续代码使用的是校验后的值还是原始输入
- 第三方响应结构变化时会怎样失败

## S03.03 schema、数据库、类型三方漂移

**定位**：校验 schema、数据库 schema / ORM 模型、类型定义、API 文档。

- 同一实体在三处的字段名、可空性、类型是否一致
- 以哪一处为事实源，其余是否由它生成
- 已经漂移的字段清单

## S03.04 空值与穷尽性

**定位**：非空断言、数组下标访问、查找结果、枚举分支。

- 非空断言（`!`、`unwrap`）是否有依据
- 未判空就使用的查找结果与数组元素
- 枚举 / 联合类型的 switch 是否穷尽，新增枚举值时编译器能否报错

## 构建与 CI

## S03.05 构建配置与检查严格度

**定位**：编译配置、lint / format 配置、框架配置、monorepo 任务编排配置。

- 严格模式、空检查是否开启
- 是否用大范围排除目录绕过检查
- 各包配置是否一致，规则之间是否冲突
- 被长期忽略的构建告警

## S03.06 构建可复现与产物内容

**定位**：锁文件、工具链版本声明、构建脚本、打包配置。

- 锁文件是否提交，CI 是否用冻结模式安装
- 语言 / 工具链版本是否声明
- 构建时是否读取本地 env 文件
- 产物中是否混入测试、夹具、源映射、密钥

## S03.07 CI 门禁完整性与假门禁

**定位**：CI 配置。无 CI 时记录为一条发现并跳过。

- lint / typecheck / test / build 是否都在 CI 中运行
- 是否是合并必需检查
- `continue-on-error`、被注释掉的步骤、只在部分路径触发的检查
- 覆盖率等阈值是否低于当前实际值（形同虚设）

## S03.08 CI 权限与 secrets

**定位**：CI 工作流的权限声明、secrets 使用、触发条件。

- 工作流默认权限是否只读，按 job 提升
- fork 来的 PR 能否拿到 secrets（`pull_request_target` 配合检出 PR 代码）
- secrets 是否只注入到需要的 job
- 是否可能在日志中打印 secrets

## S03.09 CI 第三方步骤与不可信输入

**定位**：CI 中引用的第三方 action、镜像、脚本。

- 第三方 action / 镜像是否钉死版本（最好是 commit SHA）
- PR 标题、分支名、issue 内容等不可信字符串是否直接拼进 shell
- 从网络下载并执行的脚本是否校验

## 数据迁移

## S03.10 迁移文件一致性与可逆性

**定位**：迁移目录、schema 定义。无持久化时跳过。

- 迁移文件与 schema 定义是否一致，序号是否冲突
- 删列、改类型等不可逆操作有无回滚或分步方案
- 大表迁移是否会锁表

## S03.11 新旧版本共存兼容

**定位**：最近的迁移与相关代码改动。

- 滚动发布期间，旧代码遇到新 schema、新代码遇到旧 schema，是否都能运行
- 迁移与代码部署的先后顺序是否有约定

## S03.12 旧数据兼容与回填

**定位**：读取持久化数据的代码、回填脚本。

- 旧数据中的 null、旧枚举值、旧 JSON 结构，新代码是否处理
- 回填脚本是否幂等，中断后能否续跑
- 持久化的 JSON 列、缓存值、队列消息是否带版本字段

## S03.13 嵌入式与本地数据库升级

**定位**：SQLite、WASM 数据库、客户端 IndexedDB 等本地存储的初始化与升级代码。无则跳过。

- 版本升级路径是否完整
- 升级中途失败后数据是否可恢复
- 多个标签页 / 进程同时打开时的升级冲突

## 状态机与并发模型

## S03.14 状态定义与转移合法性

**定位**：业务状态字段、任务 / 作业状态、审批流、对话回合状态。

- 状态是显式枚举，还是用多个布尔字段组合表达
- 非法转移是否被拒绝，转移判断是否集中在一处
- 状态转移是否有记录

## S03.15 卡死中间态与重启恢复

**定位**：会进入「进行中」状态的任务与流程。

- `processing` 类中间态是否可能永远不结束，有无超时回收
- 进程重启后，进行中的任务如何恢复
- 能否从数据直接看出卡在哪一步

## S03.16 并发状态转移

**定位**：修改状态字段的所有代码。

- 两个请求同时推进同一状态时，是否用条件更新保证只成功一次
- 状态修改与副作用的先后顺序

## S03.17 取消、撤销与副作用

**定位**：取消、撤销、回滚操作。

- 取消后状态与已发生副作用（外部调用、扣费、通知）是否一致
- 取消请求与完成事件同时到达时的处理

## 扩展系统（无插件 / skill / 工具注册机制时整组跳过）

## S03.18 扩展注册表一致性

- 每个扩展单元的元数据是否完整（名称、描述、入口、版本）
- 注册表声明与磁盘实际内容是否一致
- 命名冲突与重复注册

## S03.19 扩展路由与契约

- 多个候选如何选择；冲突与无匹配时的兜底
- 输入输出契约、错误约定、超时
- 路由逻辑是否可测试

## S03.20 扩展隔离与提示注入

- 各扩展之间的资源、命名空间、配置是否互相污染
- 扩展能访问的文件系统、网络、凭据是否最小化
- 扩展读取的外部内容是否可能被当作指令执行

## 接口与模块边界

## S03.21 API 响应形状与错误语义

**定位**：对外 API 的响应构造与错误处理。

- 成功与错误响应结构是否统一
- 是否用 200 返回失败
- 校验错误是否定位到字段
- 同类资源的字段命名与空值表达是否一致

## S03.22 API 版本化与破坏性变更

**定位**：对外 API、库的公共导出、事件 / 消息结构。

- 近期改动是否删除字段、改类型、改语义、收紧校验
- 有无版本机制与废弃流程
- 契约文档（OpenAPI、schema）是否由代码生成，是否与实现一致

## S03.23 模块分层与依赖方向

**定位**：模块 / 包之间的 import 关系。

- 表现层是否直接访问持久层
- 共享包是否反向依赖应用
- 依赖方向是否有 lint 规则或架构测试保证

## S03.24 循环依赖与深层导入

**定位**：模块 import 图。

- 包级与文件级循环依赖
- 通过深层路径导入其他包的内部实现
- 桶文件导致内部实现成为事实上的公共 API

## 容器与部署（无容器 / IaC 时整组跳过）

## S03.25 Dockerfile 与镜像

- 基础镜像是否钉版本
- 是否以非 root 运行
- secrets 是否通过构建参数进入镜像层
- `.dockerignore` 是否排除 `.git`、依赖目录、密钥
- 多阶段构建与层顺序

## S03.26 容器运行配置

**定位**：compose、k8s manifest、helm chart。

- 健康检查定义；存活探针是否依赖外部服务（会导致级联重启）
- 资源请求与上限
- 停止信号与优雅退出等待时间
- secrets 是否以明文放在配置中

## S03.27 IaC 安全

**定位**：terraform、pulumi、云资源配置。

- 公开可访问的存储桶、数据库、端口
- 过宽的 IAM 权限
- 未加密的存储与备份
- state 文件的存放与访问控制

## S03.28 部署、回滚与迁移时序

**定位**：部署脚本、发布流水线、迁移执行方式。

- 能否一键回滚到上一版本
- 不可逆迁移是否会让回滚失效
- 迁移在部署流程中何时执行，失败怎么办
- 发布后的冒烟检查
