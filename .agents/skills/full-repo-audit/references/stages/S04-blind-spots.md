# S04 盲区扫荡

覆盖前三个阶段没有触及的表层领域。**每个维度一轮。** 开始本阶段前读 S01-S03 摘要。

---

## 配置与机密

## S04.01 忽略规则与仓库属性

**定位**：`.gitignore`、`.gitattributes`、`.editorconfig`。

- `.gitignore` 是否覆盖实际产生的产物、缓存、日志目录
- 是否误忽略了源文件
- 已被 git 跟踪、但本应被忽略的文件
- 行尾与二进制文件标记

## S04.02 env 示例与配置说明

**定位**：`.env.example` 等示例文件、配置读取代码、配置文档。

- 示例文件是否列全代码实际读取的所有变量
- 示例文件中是否误填了真实值
- 每个变量是否说明用途、是否必需、默认值

## S04.03 工具配置冲突

**定位**：格式化、lint、编辑器、提交钩子的配置。

- 格式化工具与 lint 规则是否互相冲突
- 多个工具管理同一件事（两个格式化工具）
- 根配置与子包配置的覆盖关系是否符合预期

## S04.04 工作区机密

**定位**：整个工作区。

- key、token、密码、私钥、数据库连接串、云凭据
- 容易被忽略的位置：测试夹具、快照、文档示例、注释掉的代码、notebook 输出、CI 配置
- 日志样例、错误截图中的凭据

发现真实凭据：只报告位置和轮换步骤，报告中不写凭据值，不自动处理。

## S04.05 git 历史机密

**定位**：git 历史（`git log -p`，或 gitleaks / trufflehog）。

- 历史中出现过、之后被删除的凭据（视同已泄露）
- 曾被提交后删除的 `.env`、密钥文件
- 仓库是否曾经公开或被推送到其他远端

## S04.06 客户端产物中的密钥

**定位**：前端 / 客户端代码、构建产物、公开前缀的环境变量。

- 服务端密钥是否被打进客户端产物
- 公开前缀（`NEXT_PUBLIC_`、`VITE_` 等）的变量是否被用于敏感值
- 移动端 / 桌面端安装包中的硬编码密钥

## S04.07 默认密钥兜底

**定位**：读取密钥与安全配置的代码。

- `SECRET || 'dev-secret'` 这类在生产环境会静默生效的默认值
- 缺少必需密钥时是否启动失败（应该失败）
- 开发便利设置（跳过认证、放开 CORS、详细错误页）是否可能在生产开启

## 文档

## S04.08 设计文档与过程记录

**定位**：docs 目录、设计文档、fixlog、backlog、review 记录。

- 是否存在，是否仍在维护
- 文档目录是否有索引
- 描述已删除功能的过期文档是否标注归档

## S04.09 README 可执行性

**定位**：README 与快速开始文档。

- 是否说明：做什么、怎么跑、怎么测、目录导览
- 文档里的命令逐条核对：命令是否存在、路径是否正确
- 前置依赖是否写全

## S04.10 文档链接与交叉引用

**定位**：所有 markdown 文档。

- 相对链接、锚点、图片引用是否有效
- 两篇文档对同一事实说法是否矛盾
- 文档中提到的文件路径、函数名是否仍然存在

## S04.11 版本号与 CHANGELOG

**定位**：manifest、CHANGELOG、fixlog、代码中的版本常量。

- 版本号在各处是否一致
- fixlog 中的修复是否都映射进了 CHANGELOG
- CHANGELOG 是否标注破坏性变更

## 测试

## S04.12 测试模式

**定位**：全部测试文件。

- 行为测试，还是读源文件断言字符串的文本扫描测试
- 文本扫描测试的清单与数量

## S04.13 覆盖缺口清单

**定位**：源码模块与测试文件的对应关系。

- 没有任何测试的关键模块（认证、授权、支付、数据写入、状态机）
- 只有 happy path 测试的关键模块

## 残留与资源

## S04.14 产物与本地数据入库

**定位**：仓库中被跟踪的文件。

- 构建产物、日志、缓存、本地数据库文件、覆盖率报告
- `public/`、`outputs/`、`tmp/` 中的运行时产物
- 运行时输出目录是否有清理策略

## S04.15 大文件与二进制

**定位**：仓库中最大的文件（画像中的大文件列表）。

- 是否应该使用 LFS 或移出仓库
- 历史中已删除但仍占用体积的大文件
- 来源不明、无法从源码复现的二进制

## S04.16 临时、备份与冲突残留

**定位**：仓库中被跟踪的文件。

- 个人临时文件、`.old` / `copy` 备份文件
- 合并冲突残留（`.orig`、`.rej`）
- 系统垃圾文件（`.DS_Store`）

## S04.17 字体与图标

**定位**：字体目录、图标资源、favicon。

- 引用的字体文件是否都存在，是否有未使用的字体
- 字体子集化与格式
- favicon 与图标体积

## S04.18 图片资源

**定位**：图片目录与引用处。

- 图片体积与格式
- 未被任何地方引用的图片
- 缺少尺寸声明导致的布局跳动

## S04.19 标准文件

**定位**：仓库根目录与站点根目录。

- LICENSE、SECURITY.md 是否存在（按项目类型）
- 站点项目的 robots.txt、manifest、sitemap
- 许可证声明与 manifest 中的声明是否一致
