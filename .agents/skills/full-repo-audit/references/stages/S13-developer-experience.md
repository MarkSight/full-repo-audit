# S13 开发者体验

检查开发者工具链。**每个维度一轮。** 开始本阶段前读 S04（文档）与 S12 摘要。

---

## CLI 与脚本

## S13.01 CLI 子命令与帮助

**定位**：仓库提供的 CLI、`bin` 目录。无 CLI 时跳过。

- 子命令清单与文档是否一致
- `--help` 是否覆盖所有子命令与参数
- 是否有版本命令

## S13.02 CLI 错误处理与退出码

**定位**：CLI 的错误处理路径。无 CLI 时跳过。

- 错误信息是否可读，是否说明怎么修
- 失败时退出码是否非零，是否区分错误类别
- 调试模式下才输出完整堆栈

## S13.03 开发脚本健壮性

**定位**：scripts 目录、Makefile、任务定义。

- 是否有 `set -euo pipefail` 或等价的失败即停
- 是否有用法说明
- 重复执行是否安全
- 在 macOS / Linux / Windows 上是否可用（按团队实际情况）

## 开发与调试

## S13.04 环境分支与调试变量

**定位**：环境判断的条件分支、调试相关环境变量。

- 只在生产环境才会执行、没有测试覆盖的分支
- 调试用环境变量是否有文档
- 环境判断是否集中

## S13.05 热重载与日志级别

**定位**：开发服务器配置、日志配置。

- 热重载是否可用、是否足够快
- 能否不改代码就调整日志级别
- 是否有种子数据与测试账号

## 贡献流程

## S13.06 贡献文档与实际流程

**定位**：CONTRIBUTING、PR 模板、README 中的开发说明。

- CONTRIBUTING.md 是否存在
- 描述的流程（分支、提交规范、评审、发布）是否与实际一致

## S13.07 测试工具配置

**定位**：测试框架配置。

- watch 模式能否使用
- 覆盖率报告能否生成
- 能否只运行受影响的测试

## S13.08 安装钩子

**定位**：postinstall、prepare 等安装钩子，pre-commit 钩子。

- 安装钩子做了什么，是否会失败或过慢
- pre-commit 钩子是否过慢（过慢会被 `--no-verify` 绕过）

## S13.09 从零 setup 实测

**定位**：README 与贡献文档中的环境搭建步骤。

- 按文档从干净环境逐步搭建
- 记录哪一步跑不通、缺少哪些文档没写的隐性知识
- 从克隆到跑通测试一共需要多少步
