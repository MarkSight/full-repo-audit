# S01 功能与交互层

从用户直接看到、用到的部分开始。**每个维度是一轮**，只把当前维度的小节交给 agent。

无 UI 的仓库（CLI、库、纯服务）：跳过 S01.01–S01.15 与 S01.18–S01.19，改跑文末 S01.A1–S01.A8。

---

## S01.01 主操作路径与配置喧宾夺主

**定位**：路由表或页面目录中的主要页面，及其直接使用的组件。

- 主操作是否一眼可见，配置控件是否抢占主视觉
- 完成核心任务要几步，有无多余的确认、跳转、弹窗
- 同类操作在不同页面的入口位置与交互方式是否一致
- 高频操作是否被埋进二级菜单

## S01.02 表单与校验

**定位**：所有表单组件及其提交处理。

- 校验时机（输入中 / 失焦 / 提交）是否统一、合理
- 错误是否定位到具体字段，并说明怎么改
- 提交失败后，已填内容是否保留
- 长表单：分步、草稿保存、离开前未保存提醒
- 重复提交防护（按钮禁用、请求去重）

## S01.03 危险操作防护与撤销

**定位**：删除、覆盖、发布、批量修改等不可逆操作的入口。

- 是否有确认；确认文案是否说明后果与影响范围
- 能否撤销（撤销优于确认弹窗）
- 确认按钮是否是具体动作（「删除 3 个项目」），而不是「确定」

## S01.04 拖拽与直接操作

**定位**：画布、看板、拖拽排序、可调整大小的组件。

- 拖动中放置目标的反馈
- 按 Esc 或拖出区域时的取消行为
- 越界处理，靠近容器边缘时自动滚动
- 拖拽结果是否持久化；保存失败时位置是否回滚
- 是否有键盘替代操作

## S01.05 批量与多选

**定位**：支持多选与批量操作的列表、表格、画布。

- 选中态是否清晰；跨页、跨筛选时选中范围是否明确
- 执行批量操作前是否告知影响数量
- 部分成功、部分失败时的反馈
- 批量操作完成后列表状态是否正确刷新

## S01.06 编辑状态持久化

**定位**：编辑器、画布、长表单、可编辑列表。

- 刷新、切页、关闭标签页后，编辑内容是否丢失
- 自动保存的时机与保存状态提示
- 撤销 / 重做栈是否正确
- 多标签页或多设备同时编辑时，是否互相覆盖且没有提示

## S01.07 设置与配置面板

**定位**：设置页、偏好面板、配置弹窗。

- 弹窗还是就地编辑的选择是否合理；有无多层弹窗嵌套
- 高频项与低频 / 高级项是否分层
- 保存方式（自动 / 手动）在各设置页是否统一
- 默认值是否合理，能否重置
- 设置变更是立即生效，还是需要刷新（是否有提示）

## S01.08 页面结构与分区顺序

**定位**：列表页、详情页、多步骤工作流页面。

- tab / 分区顺序是否符合使用频率与流程先后
- 最重要的信息是否在首屏
- 同类页面的布局结构是否一致

## S01.09 加载态与骨架屏

**定位**：所有异步获取数据的区块。

- 每个数据区块是否都有加载态
- 骨架屏与真实布局是否匹配（加载完成时跳动）
- 请求很快时是否闪烁（最短展示时间或延迟显示）
- 局部刷新时是否整页进入 loading

## S01.10 空状态

**定位**：所有可能为空的列表、面板、搜索结果。

- 首次使用、筛选无结果、无权限三种空态是否区分
- 空态是否给出下一步操作
- 删除到列表为空之后的状态

## S01.11 导航与页面状态恢复

**定位**：路由配置、带筛选 / 排序 / 分页 / tab 的页面。

- 筛选、排序、分页、当前 tab 是否反映在 URL 中
- 浏览器前进、后退是否行为正确
- 分享深链接后能否打开同一视图
- 从详情返回列表时是否回到原滚动位置

## S01.12 流式渲染与滚动

**定位**：聊天面板、流式输出区域、日志流。

- 增量更新时是否闪烁或整体重排
- 半截 markdown、代码块、表格的渲染
- 新内容自动滚到底；用户向上翻看时不抢滚动；有「回到底部」
- 长会话的渲染性能

## S01.13 实时连接可靠性

**定位**：WebSocket、SSE、轮询相关代码。

- 断线提示与自动重连（带退避）
- 重连后消息的重复、丢失、乱序
- 点击停止 / 取消后，后端任务是否真的停止
- 页面隐藏或离开后，连接与轮询是否停止

## S01.14 媒体预览与候选选择

**定位**：图片、视频、音频、文件预览组件，生成结果的候选选择。

- 加载中、加载失败、比例与裁剪
- 候选结果的选中态，切换后相关状态是否同步
- 大量缩略图：懒加载、尺寸、object URL 是否释放
- 媒体播放状态与资源释放

## S01.15 上传流程

**定位**：上传组件与上传处理接口。

- 进度、取消、失败重试
- 类型与大小限制是否在上传前提示
- 大文件是否需要分片或断点续传
- 上传完成前离开页面的处理

## S01.16 核心共享包的 API 一致性

**定位**：被多个应用或模块依赖的共享包（shared / common / core 等）。

- 同类 API 的命名、参数顺序、返回形态是否一致
- 共享 schema 与各使用方实际使用的字段是否漂移
- 共享包中是否混入了某个业务的专属逻辑
- 导出面是否过宽，内部实现被外部直接依赖

## S01.17 客户端 API 调用层

**定位**：前端 / 客户端的请求封装与数据获取 hook。

- 错误响应是否统一处理，有无被忽略的错误
- 请求与响应类型是否与服务端一致
- 重复请求去重；组件卸载后请求是否取消
- 登录过期的统一处理

## S01.18 主题与暗色模式

**定位**：主题 token、全局样式、组件样式。

- 暗色 / 亮色下的对比度与可读性（含禁用态、图表、阴影）
- 切换主题时是否闪烁
- 绕过主题 token 的硬编码颜色

## S01.19 响应式与跨端

**定位**：布局组件、断点定义、移动端专属逻辑。

- 小屏布局断裂、横屏、超宽屏
- 触控目标尺寸；仅悬停可用的功能在触控端的替代
- 虚拟键盘遮挡输入；移动端视口高度变化
- 使用了目标浏览器不支持的 API

## S01.20 文案与术语一致性

**定位**：界面文案、i18n 资源、错误信息、文档。

- 同一概念在界面、文档、错误信息中是否同名
- 按钮文案是否是具体动作
- 错误文案是否说明：发生了什么、为什么、怎么办
- 语气与人称是否统一

## 无 UI 仓库替代维度

## S01.A1 命令与接口清单

**定位**：CLI 入口、子命令注册、HTTP 路由表、库的导出入口。

- 实际命令 / 接口与文档是否一一对应
- 有无隐藏的、废弃未删的、文档里有但实际不存在的

## S01.A2 参数与默认值

- 必填参数是否过多
- 默认值是否安全、合理
- 参数命名在各命令 / 接口之间是否一致

## S01.A3 错误信息与退出码

- 错误信息是否说明原因与修法
- 退出码 / 错误码是否区分类别
- 是否把完整堆栈直接抛给最终用户

## S01.A4 输出格式

- 数据输出到 stdout，日志输出到 stderr
- 是否支持结构化输出（如 `--json`）
- 非 TTY 环境下是否关闭颜色与交互式进度条

## S01.A5 长任务进度与中断

- 长任务是否有进度展示
- Ctrl-C 中断后是否清理临时文件与子进程
- 中断后重跑是否安全

## S01.A6 非交互运行与危险操作

- 所有交互提示是否都有参数或环境变量替代，可在 CI 中运行
- 危险操作是否默认保守，需要显式 `--yes` / `--force`
- 是否支持 `--dry-run`

## S01.A7 示例可运行性

- README 与 `--help` 中的示例能否原样运行
- 示例输出是否与当前版本一致

## S01.A8 库公共 API 易用性

- 最小可用示例是否足够短
- 公共 API 与内部实现是否分离
- 版本变更是否符合 semver 承诺
- 类型定义是否随产物发布
