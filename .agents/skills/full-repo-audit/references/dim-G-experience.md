# W7 体验层（条件适用）

适用性由画像决定：有 UI 才查 G1-G5、G7；有 CLI 或是库才查 G6。
后置的理由：表层改动最容易被底层契约/数据修复推翻，先修底层再调表层可避免返工。

审查单位是**用户任务**，不是文件。先从画像里列出 3-8 条主要用户旅程
（例如：注册→首次使用→完成核心任务→出错恢复→邀请协作→导出/注销），
每条旅程端到端走一遍，再按下面维度归因。

---

## G1 流程与信息架构

1. **核心任务路径长度**：完成主要任务需要几步、是否有不必要的中间页/弹窗/确认；
   新用户首次完成核心任务的路径是否顺畅（空数据状态下是否仍可理解）。
2. **配置喧宾夺主**：高级/罕用配置是否占据主视觉位置，
   常用操作是否被埋在次级菜单（旧版专门列此项，属高频真实问题）。
3. **模态与就地编辑**：是否滥用模态打断流程；
   多层模态嵌套；模态内的长表单与滚动；关闭模态是否丢失输入。
4. **导航一致性**：当前位置是否可感知、返回是否回到预期位置、
   深链接是否可分享与恢复、浏览器前后退是否行为正确、
   刷新后状态是否保留（滤镜、分页、展开状态、草稿）。
5. **信息密度与分组**：同屏信息是否超出理解负荷、
   相关控件是否就近、视觉层级是否反映重要性、
   同类信息在不同页面是否用同一种表达。
6. **批量与多选操作**：是否支持、选中状态是否清晰、
   危险批量操作是否有范围确认与撤销。
7. **破坏性操作防护**：删除/覆盖/发布/不可逆操作是否有确认、
   确认文案是否说明后果与范围、是否提供撤销（优于确认弹窗）。
8. **拖拽与直接操作**（画布/看板/排序类界面）：
   放置目标是否可感知、是否可键盘替代（与 G2 联动）、
   中途取消、越界与自动滚动、操作结果是否持久化、
   并发编辑冲突（与 C4-7 联动）。
9. **表单体验**：校验时机（输入中 vs 提交时）、错误定位到字段、
   保留已填内容、长表单的分步与进度保存、
   自动保存的状态提示、离开前未保存提醒。
10. **反馈及时性**：操作后是否有明确结果反馈、
    乐观更新失败时是否正确回滚并告知、
    长任务是否有进度与可取消。

## G2 可访问性（WCAG 2.1/2.2 AA）

1. **键盘可达**：所有交互可 Tab 到达与激活、
   焦点顺序符合视觉顺序、无键盘陷阱、
   自定义控件支持对应按键（Esc 关闭、方向键移动、Enter/Space 激活）。
2. **焦点管理**：焦点可见（不要移除 outline 而不补替代）、
   模态打开时移入与关闭时归还、
   动态内容出现时焦点处理、路由切换后焦点与标题更新。
3. **语义与无障碍名**：用原生语义元素优先；
   自定义控件的 role/state（`aria-expanded`、`aria-selected`、`aria-invalid`）；
   图标按钮的可读名称、装饰性图像 `alt=""`、
   表单 label 关联、错误信息与字段的 `aria-describedby`。
4. **动态通知**：加载/成功/错误/校验是否对屏幕阅读器可感知（live region）；
   toast 是否会被错过。
5. **对比度与视觉**：文本与 UI 组件对比度达标（含暗色主题、
   禁用态、占位符、图表颜色）、不单靠颜色传达信息、
   文本可缩放到 200% 不破版、触控目标尺寸。
6. **动效**：尊重 `prefers-reduced-motion`、
   无自动播放与闪烁、长动画可跳过。
7. **结构**：标题层级、landmark、跳转到主内容链接、
   页面标题唯一且描述当前内容、语言属性。
8. **表格与复杂组件**：表头关联、排序状态可感知、
   虚拟列表对辅助技术的可用性。
9. **工具与测试**：有无自动化 a11y 检查（axe 等）在 CI
   （没有就交 L4），以及手工键盘走查记录。

## G3 国际化与本地化

1. **硬编码文案**：界面/错误信息/邮件模板/导出文件中未提取的字符串；
   是否包含拼接语句（无法正确翻译）。
2. **key 完整性**：各 locale 缺失 key、孤儿 key、
   回退语言策略、缺翻译时的表现（显示 key 是 bug）。
3. **复数与性别**：是否用了支持复数规则的机制（不是 `count > 1 ? 's' : ''`）、
   序数、列表连接、单位。
4. **格式本地化**：日期/时间/时区、数字与千分位、货币与符号位置、
   百分比、地址与姓名顺序、电话与邮编校验（与 C8 联动）。
5. **RTL 支持**：布局镜像、逻辑属性（start/end 而非 left/right）、
   图标方向、混排文本。
6. **文本伸缩**：长翻译（德语/芬兰语）下的截断与换行、
   固定宽度按钮、省略号是否丢失信息。
7. **locale 检测与切换**：来源优先级（用户设置 > 账号 > 浏览器 > 默认）、
   切换是否全站生效与持久化、SSR 与客户端是否一致、
   URL 中的 locale 与 SEO。
8. **非界面本地化**：邮件/通知/PDF/导出/AI 输出语言是否跟随用户偏好。

## G4 响应式与跨端

1. 断点覆盖：小屏到大屏的布局断裂、横屏、超宽屏、
   可折叠设备；缩放与系统字号放大。
2. 触控适配：点击区域、悬停专属功能在触控端的替代、
   手势冲突（页面滚动 vs 画布拖拽）、长按菜单。
3. 安全区与视口：刘海/底部指示器、
   移动端地址栏高度变化、虚拟键盘遮挡输入。
4. 浏览器/运行时兼容：目标矩阵是否明确、
   使用的 API 是否超出目标范围、是否有优雅降级、
   Safari/iOS 特有问题（日期输入、滚动、视频自动播放）。
5. 主题：暗色/亮色/跟随系统、
   切换闪烁（FOUC）、
   所有状态（禁用、错误、高亮、图表、阴影、图片）在两种主题下均可读。
6. 打印与导出视图（若业务需要）。
7. 原生/混合端特有项（若适用）：返回键、深链接、权限弹窗、
   后台恢复、版本升级兼容。

## G5 空态、载态、错态与离线

1. **四态齐备**：每个数据驱动区域是否都有
   加载 / 空 / 错误 / 成功 四种表现，而不是只有成功态。
2. **骨架屏与真实布局匹配**：骨架与最终内容尺寸不一致会造成跳动；
   是否有最短展示时间避免闪烁。
3. **空态质量**：是否解释「为什么空」与「下一步做什么」
   （首次空 vs 筛选后空 vs 权限不足空，三者文案应不同）。
4. **错误态可操作**：是否有重试、是否保留上下文、
   是否给出支持 ID（与 D4-9 联动）、
   是否把技术错误直接抛给用户。
5. **局部失败**：单个区块失败不应炸掉整页；
   错误边界覆盖范围是否合理（过粗会整页白屏，过细会噪音）。
6. **乐观更新**：失败回滚是否恢复原状并告知；
   回滚是否造成内容跳动或丢失用户后续输入。
7. **离线与弱网**：断网提示、重连恢复、
   未发送的操作是否排队或明确失败、
   超时后的用户可见状态。
8. **权限态**：无权限时是界面隐藏还是报错；
   隐藏是否导致用户困惑（与 B2-3 联动：隐藏不等于授权检查）。

## G6 CLI 与库的开发者体验

**适用**：仓库提供 CLI 或作为库被引用。

1. **CLI 帮助**：`--help` 覆盖所有子命令与参数、
   有用法示例、参数默认值可见、版本命令存在。
2. **CLI 约定**：退出码语义（0 成功 / 非 0 分类）、
   stdout 输出数据、stderr 输出日志（便于管道组合）、
   支持 `--json` 结构化输出、颜色在非 TTY 下自动关闭、
   `--quiet`/`--verbose`、读取 stdin。
3. **错误信息**：说明哪里错了、期望什么、怎么修；
   不要打印整个堆栈给最终用户（`--debug` 下再打印）。
4. **交互与非交互**：是否可在 CI 中非交互运行
   （所有提示都有参数/环境变量替代）、
   危险操作的 `--yes` 与默认保守行为、
   长任务的进度与可中断（Ctrl-C 后清理，与 D2-7 联动）。
5. **幂等与可重复**：重复执行的后果、
   `--dry-run` 支持、操作前的状态检查。
6. **库的易用性**：最小可用示例是否 5 行内可跑、
   默认配置是否安全合理、
   必填参数是否过多、
   错误类型是否可被调用方区分（与 E2-8/L1 联动）。
7. **安装与分发**：安装说明可验证、
   产物包含类型定义/源映射、
   体积与依赖数是否克制、
   支持的运行时版本矩阵明确。

## G7 文案与术语一致性

1. **术语表一致**：同一概念在 UI/文档/错误信息/API 中是否同名
   （「项目/空间/工作区」混用是典型问题）。
2. **语气与人称一致**：是否混用「您/你」、
   命令式与陈述式混杂、
   技术术语直接暴露给非技术用户。
3. **按钮与标题**：动作按钮用动词、与其触发的结果一致、
   确认弹窗的按钮文案说明具体后果（不是「确定/取消」）。
4. **错误文案三要素**：发生了什么、为什么、现在能做什么；
   避免「未知错误」、避免把内部错误码当文案。
5. **占位符与示例**：占位符不当作 label 用、
   示例数据不误导（不要看起来像真实数据）。
6. **大小写与标点规范**一致；中英混排空格规则；品牌名拼写。
7. **可读性**：句子长度、专业术语是否首次出现时解释、
   数字与单位格式统一。
